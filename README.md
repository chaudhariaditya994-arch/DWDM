## ⚡ Quick Start Commands

### 1. Start the Flask Backend (Port 5000)
```powershell
cd "d:\DWDM project\ecommerce-data-mining\backend"
python -m pip install -r requirements.txt
python app.py
```

### 2. Start the Vite React Frontend (Port 5173)
```powershell
cd "d:\DWDM project\ecommerce-data-mining\frontend"
npm install --legacy-peer-deps
npm run dev -- --host 127.0.0.1 --port 5173
```

### 3. Open in Browser
- **Frontend Dashboard:** [http://127.0.0.1:5173](http://127.0.0.1:5173)
- **Backend API:** [http://127.0.0.1:5000](http://127.0.0.1:5000)

### 4. Run Automated Verification Test
```powershell
cd "d:\DWDM project"
python ecommerce-data-mining/verify_full_system.py
```
